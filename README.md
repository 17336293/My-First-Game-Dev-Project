# My First Game Dev Project

An old project of mine from my master’s program — I had to develop an arcade machine–style program that let you play the Monty Hall problem, as well as a few other games like Rock, Paper, Scissors.

I debated including this project, as it’s not especially relevant to my portfolio, but it holds immense sentimental value. At the time of writing, I was thinking about making my own video game but doubted myself, telling myself it would be too much work and that I’d be starting from scratch. This project is a reminder that I’m not starting from scratch — I made my first game when I was 22, and maybe someday I’ll make another, more ambitious one.

Though I doubt I’ll be making Baldur’s Gate 4 any time soon :smile:
