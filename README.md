# My First Game Dev Project

An old project of mine from my masters, I had to develop an arcade machine-esque program that would let you play the Monty Hall problem, as well as a few other games such as Rock, Paper, Scissors.

I debated including this project, as its not especially relevant to my porfolio, but it has an immense amount of sentimental value. At the time of writting, I thought about making my own video game but doubted myself, saying it would be too much work, that I'd be starting from scratch. This project is a reminder that I amn't starting from scratch, I made my first game when I was 22, and mabye some timeI'll make another, more ambitious game.
